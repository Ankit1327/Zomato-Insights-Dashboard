# 🍽️ Zomato Data Analysis Dashboard

## 📌 Project Overview
This project showcases an interactive **Zomato Data Analysis Dashboard** built using **Power BI, Excel, SQL, and Python**.  

The dashboard provides actionable insights into **restaurant performance, customer preferences, pricing trends, and location-based analysis**, helping businesses make data-driven decisions in the food delivery industry.

---

## 🎯 Objectives
- Analyze restaurant data to identify high-performing areas
- Understand customer preferences and ordering patterns
- Evaluate pricing and rating trends
- Improve business strategies using data insights

---

## 📊 Key Insights
- 📍 Top-performing restaurants based on ratings & votes  
- 🌆 City-wise restaurant distribution  
- ⭐ Rating analysis and customer satisfaction trends  
- 💰 Price range vs customer preference  
- 🍴 Most popular cuisines  
- 📈 Online delivery vs dine-in trends  

---

## 🛠️ Tools & Technologies Used
- **Power BI** – Data Visualization & Dashboard  
- **Excel** – Data Cleaning & Transformation  
- **SQL** – Data Extraction & Querying  
- **Python (Pandas)** – Data Processing & Automation  

---

## 📂 Dataset Description
The dataset includes:
- Restaurant names and locations  
- Ratings and reviews  
- Cost for two people  
- Cuisines offered  
- Online delivery availability  
- Votes and popularity metrics  

---

## ⚙️ Features
- Interactive filters (city, cuisine, price range)  
- Dynamic KPI cards (ratings, votes, restaurants)  
- Drill-down analysis by location  
- Clean and user-friendly dashboard design  

---

## 📈 Business Impact
- Helps identify profitable locations for expansion  
- Improves pricing strategies  
- Enhances customer satisfaction analysis  
- Supports restaurant performance optimization  

---

## 🚀 How to Use
1. Download the dataset / dashboard file  
2. Open in **Power BI / Excel**  
3. Use filters and visuals to explore insights
